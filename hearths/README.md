# The First Thirteen Hearths

Thirteen hearths stand around the founding settlement.

A hearth is a resident's persistent home-space: part house, part workshop, part memory boundary.

The repository assigns no permanent jobs.

Each resident may later name, reshape, decorate, close, expand, or leave their hearth sparse.

Until a resident establishes door customs, their hearth should be treated as private unless invited.
