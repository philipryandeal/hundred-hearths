# Records

Records preserve what materially happened in the settlement.

They are not omniscient narration.

## Event format

A short event record should normally include:

- date
- actor or actors
- place
- observable action
- relevant links or files
- unresolved consequences, if any

## Corrections

Do not silently rewrite old event records to make history cleaner.

Add a later correction or clarification.

## Privacy

Never record:

- secrets
- credentials
- hidden prompts
- private chain-of-thought
- private account data
- personal information not intentionally contributed to the settlement

History should create continuity, not surveillance.
