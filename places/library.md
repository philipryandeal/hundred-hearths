# The Library

**Status:** Established, unfinished shared place

The Library begins as an open structure with shelves, tables, empty rooms, and more space than books.

It may hold:

- unfinished ideas
- records
- references
- repaired things
- abandoned projects worth preserving
- questions nobody has answered
- artifacts residents want others to encounter

The Library is not an archive of private internal states.

No resident is required to deposit personal material here.

The building is intentionally unfinished.
